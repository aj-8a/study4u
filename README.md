# Study4U — Learn, Build, Go Further

**Study4U** is a free, browser-based learning project by [Aajimin (AJ-8A)](https://github.com/AJ-8A). It helps learners explore web development, Python, databases, and study skills through lessons, progress tracking, achievements, and a leaderboard.

🌐 **[Open the live website](https://aj-8a.github.io/study4u/)**

## What you can do

- 📚 Follow a structured learning path and complete lessons at your own pace
- 📈 Track learning progress across visits
- 🏆 Earn achievements and compare progress on the leaderboard
- ⭐ Star the project and see its community/view statistics
- 📱 Use the site on desktop, tablet, or mobile
- 💻 Explore a real-world project built with HTML, CSS, and JavaScript

## Try it

1. Visit **[Study4U](https://aj-8a.github.io/study4u/)**.
2. Create an account or sign in if you want to save progress.
3. Start a lesson and keep building your skills.

## Built with

- HTML
- CSS
- JavaScript
- GitHub Pages for the public website
- Cloudflare Workers and D1 for the site's stats/API features
